BookShop — практика: первое оформление

Что сделано:
1. Создана папка css и файл css/style.css.
2. Общий CSS подключён ко всем HTML-страницам.
3. Для body заданы шрифт, фон и цвет текста.
4. Оформлены заголовки, ссылки, карточки и навигация.
5. Добавлены классы .price и .btn.

Как проверить:
- Открой index.html в браузере.
- Перейди по ссылкам Главная, Каталог и Корзина.
- Открой инструменты разработчика (F12), выбери элемент и посмотри вкладку Styles.
- Измени цвет в css/style.css и обнови страницу — стиль должен измениться.

Примечание:
Это учебный демонстрационный шаблон. Корзина и оформление заказа не связаны с сервером.
